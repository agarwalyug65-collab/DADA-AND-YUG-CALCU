# 🔢 Command-Line Calculator

# made by Dada and Yug calcu WITH THE HELP OF C-LAUDE

A lightweight, basic calcu which work with html css js .

---

## 🚀 Features

 Basic Arithmetic: Addition, subtraction, multiplication, and division and more 
 Advanced Operations: Exponentiation ($a^b$) and square roots ($\sqrt{x}$).
 Input Validation & Safety: Catches division by zero, square roots of negative numbers, and non-numeric inputs.
 Session History: Keeps a running list of calculations during execution.
